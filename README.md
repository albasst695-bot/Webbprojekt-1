# Webbprojekt: Anonym digital frågelåda

## Om projektet

Webbplatsen presenterar en idé om en anonym digital frågelåda för storföreläsningar. Projektet undersöker om anonymitet och enkel användning kan göra det lättare för studenter att ställa frågor och hjälpa föreläsaren att upptäcka missuppfattningar.

## Webbplatsens sidor

- `index.html` är startsidan med projektets sammanfattning.
- `amnesomrode.html` fördjupar ämnesområdet och projektets impact.
- `utmaning.html` beskriver problemet med att ställa frågor i stora föreläsningar.
- `ide.html` beskriver den föreslagna digitala lösningen.
- `hypotes.html` beskriver projektets hypotes och förväntade resultat.
- `referenslista.html` innehåller källorna.
- `style.css` innehåller den gemensamma, responsiva utformningen.

## Öppna webbplatsen

Öppna `index.html` i en webbläsare. I Visual Studio Code kan du också öppna filen och starta Live Server.
